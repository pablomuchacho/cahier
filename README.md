# Cahier

Application personnelle pour les devoirs de musique (HEM Genève — Musique et Mouvement / Dalcroze), semaine par semaine.

- **URL permanente :** [https://pablomuchacho.github.io/cahier/](https://pablomuchacho.github.io/cahier/)
- **100 % autonome sur iPhone :** Aucune dépendance envers le Mac allumé. Fonctionne en 5G, sur tous les Wi-Fi et hors-ligne.
- **Dictée vocale directe :** Bouton « Dicter un devoir », le texte transcrit va directement dans le cours cité ou sélectionné.
- **Planning officiel intégré :** Horaires des cours (Pascale Rochat, Laurent Sourisse, Tamaé Gennai, Emilio Artessero, Florence Jaccottet, Sarah Branchi).
- **Données locales (IndexedDB) :** Tout reste confidentiel et stocké sur l'appareil.

## Installation sur iPhone

1. Ouvre dans Safari : **https://pablomuchacho.github.io/cahier/**
2. Appuie sur **Partager** (icône carré avec flèche vers le haut).
3. Sélectionne **Sur l'écran d'accueil**.
4. L'application apparaît comme une vraie app avec son icône « C » et fonctionne même sans réseau.
